## 0.3.0

> 2026-11-12 发布

### ✨ 新增功能

- `fxri-code-profile-build` 构建与质量规范，覆盖告警分源治理、barrel 断边、质量门零告警与契约生成优先
- 该技能的原则示例与能力位适配表，依赖项缺失时相关条目自动跳过
- `fxri-code-profile-display` 接口契约与数据展示规范，覆盖码值映射、字典来源、契约落差与响应信封
- 该技能的原则示例与能力位适配表，依赖项缺失时相关条目自动跳过
- `fxri-code-profile-restore` 设计还原规范，覆盖素材分工、标注直读、整图切片热区、可读下限、切片获取与可用态判定
- 该技能的原则示例与能力位适配表，依赖项缺失时相关条目自动跳过
- 组件 ref 片段感知、defineExpose 用 getter、数据源驱动容器须传数据源、表单与状态机写法
- 该技能的能力位适配表，依赖项缺失时相关条目自动跳过
- 该技能的组件与工具形态适配表，依赖项缺失时相关条目自动跳过
- C-8 破坏性变更须附迁移说明，并把 `docs/migrations/` 定为长期约定
- C-3 技能命名与 C-4 分类归属两条协作规范，按实践领域语义
- 命名门禁校验主题段最多 2 段，超出提示拆技能
- scope 受控词表与越界校验，取值限定为技术面或技术栈
- C-5 取材边界、C-6 分层与按需取用、C-7 描述与触发三条协作规范

### 🔧 功能调整

- `fxri-code-profile-vue` 升 0.3.1，正文由 5 条扩到 9 条
- `fxri-code-profile-web` 升 0.3.1，正文由 6 条扩到 19 条，补齐精度、取值、提示、布局、死代码等跨框架写法
- 常见问题与分类说明补迁移入口，文档站侧栏新增升级分组
- 技能分类改为实践领域九项（编码 / 写作 / 研究 / 设计 / 数据 / 办公 / 运维 / 生活 / 元技能），交付物降为辅助判据
- 六个技能按新体系改名并升补丁版本，`requires` 与脚本标注同步
- 技能形态收敛为规范 / 流程 / 模板，命名门禁改为全量校验并去掉分类状态字段
- 贡献指南补明主题段 1–2 段
- `fxri-writing-profile-nav` 升 0.1.5，本仓特化分组降为示例说明，404 兜底独立成节
- 贡献指南补 scope 词表与 tier 语义，并同步三段式命名规则
- 规范载体用法说明补充「载体是提炼技能的判据来源，与技能冲突时以载体为准」

### ⚡ 优化改进
