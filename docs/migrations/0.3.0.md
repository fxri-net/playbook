# 0.3.0 迁移说明

> 适用：已安装 0.2.x 及更早技能的项目。本页只写「已装旧版需要做什么」，改了什么见[更新日志](../changelog)。

## 技能改名

| 旧名 | 新名 |
| --- | --- |
| `fxri-dev-profile-web` | `fxri-code-profile-web` |
| `fxri-dev-profile-vue` | `fxri-code-profile-vue` |
| `fxri-dev-profile-restore` | `fxri-code-profile-restore` |
| `fxri-dev-profile-display` | `fxri-code-profile-display` |
| `fxri-dev-profile-build` | `fxri-code-profile-build` |
| `fxri-docs-profile` | `fxri-writing-profile-nav` |

## 分类映射

| 旧分类 | 新归属 |
| --- | --- |
| `dev` | `code` |
| `writing` | `writing`（语义收窄为写作领域） |
| `design` / `data` / `office` / `research` / `ops` / `meta` | 保留为实践领域，按技能实际用途重新归属 |
| `imported` | 取消，分类不再是来源标记 |

## 升级动作

1. 卸载旧技能目录：`fxri-dev-profile-web`、`fxri-dev-profile-vue`、`fxri-docs-profile` 以及其他 `fxri-dev-profile-*`。
2. 从本仓重新安装，六个技能一次装齐。
3. 核对安装结果：应只见新名；选择 `fxri-code-profile-vue` 时 `fxri-code-profile-web` 应被自动补全。
4. 清理 `~/.toolkit/cache/skill-sources/` 下的旧目录副本，否则新旧两份技能会同时存在、触发词冲突。
5. 项目内引用旧名的文档、脚本与配置同步为新名。

## 下游提示

各仓文档站校验脚本首行的标注须同步为 `标准来源 playbook fxri-writing-profile-nav 0.1.4`；其余引用旧技能名的地方一并替换。

## 维护者小节

发版序列固定为：`changelog version` → `sync version` → `changelog doc` → `verify` → 打标签。迁移页在发版前写好，发版后不再改动。
