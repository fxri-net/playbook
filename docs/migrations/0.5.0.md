# 0.5.0 迁移说明

> 适用：装过 `fxri-writing-profile-nav` 的项目。本页只写「已装旧版需要做什么」，改了什么见[更新日志](../changelog)。

## 技能迁出

文档站导航规范并入 `@fxri/toolkit` 的文档站写作技能，覆盖范围同时扩到页面标题与站内引用：

| 旧 | 新 |
| --- | --- |
| `fxri-writing-profile-nav`（本仓） | `fxri-docs-writing`（`@fxri/toolkit`，`tier: optional`） |

新技能除分类骨架、顶栏与 404 兜底外，还规定：页面标题写「显示名（标识）」；已声明 frontmatter `title` 的页面与 H1 逐字一致；
索引与目录表用目标页完整标题，行内引用用显示名；侧栏允许短别名，只要求指向同一对象且在同一导航分组内唯一；
长度约束按显示单位计（CJK 按字、空格分词语言按词）。

## 升级动作

1. 先升级 `@fxri/toolkit` 到含 `fxri-docs-writing` 的版本（`fxri-docs-writing` 为可选技能，安装时选中）。
2. 清理旧技能：`toolkit skills uninstall --skills fxri-writing-profile-nav`。
3. 重新加载技能：新会话中确认技能清单为 `fxri-docs-writing`，不再出现旧名。
4. 按新技能核对页面标题与索引：标题改「显示名（标识）」、索引改完整标题、行内引用改显示名；侧栏短名按「同一对象、分组内唯一」核对即可，不必逐字改成 H1。

⚠️ `docs.nav.maxGroupHan` 在新版 toolkit 中作为兼容键保留，新键为 `maxGroupUnits`（显示单位）；两者同时存在时以新键为准。

## 校验方式

- `node scripts/verify.mjs`（本仓聚合门禁）。
- 全仓检索应无 `fxri-writing-profile-nav` 残留（更新日志与归档除外）。
