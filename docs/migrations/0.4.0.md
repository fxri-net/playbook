# 0.4.0 迁移说明

> 适用：已按旧版规范在各项目里维护导航校验脚本的项目。本页只写「已装旧版需要做什么」，改了什么见[更新日志](../changelog)。

## 条款变更

`fxri-writing-profile-nav` 0.2.0 删除了三条实现类条款，改为「引用工具命令」：

| 删除的旧条款 | 现在的口径 |
| --- | --- |
| 各仓脚本首行标注「标准来源 playbook fxri-writing-profile-nav <版本>」，版本号须等于技能版本 | 不再要求标注版本，也不再要求副本同步 |
| 校验脚本是规范的投影，各仓各自维护一份实现 | 校验由 `toolkit docs nav check` / `docs dist check` 执行，规则随工具分发 |
| 本文件条款变更时须同批同步各仓副本 | 命令与条款不一致时以条款为准，同时修命令 |

## 升级动作

1. 升级工具到 `@fxri/toolkit` 1.16.12 及以上（含 `docs nav check`、`docs dist check` 与迁移助手）。
2. 把站点配置里的 `nav` / `sidebar` 数组抽成 `docs/site-nav.json`：
   - 可用 `toolkit docs nav init` 生成初稿，再人工核对；
   - 站点配置改为 `import siteNav from '../site-nav.json'` 并引用展开。
3. 删除仓库内的 `check-docs-nav.mjs` / `check-docs-dist.mjs` / `check-docs-theme.mjs`，`verify.mjs` 改调工具命令（工具未安装时打印跳过）。
4. 若 `docs/tsconfig.json` 会被 `tsc` 覆盖（如 `docs:typecheck`），确认已开启 `resolveJsonModule`。

⚠️ 阈值可在 `.toolkitrc.json` 的 `docs` 段覆盖（默认值即规范口径）；`docs.rules` 可按规则 id 关闭或降级。

## 校验方式

- `node scripts/verify.mjs`（本仓聚合门禁）。
- 全仓检索应无 `fxri-writing-profile-nav 0.` 残留（更新日志与归档除外）。
