# 设计还原规范

> 本技能版本 0.1.0（随 playbook 技能集分发）。被问版本时即报此值；与磁盘版本不一致即说明会话上下文已过期。

## 何时使用

- 按设计稿实现或核对页面，需要确定取值依据、素材来源与还原程度
- 设计稿以整图切片交付，需要在图内承载点击
- 判断设计平台是否可用、从平台取切片、对还原结果做取证

不涉及：接口字段的契约问题（见 `fxri-dev-profile-display`）、代码组织约定（见 `fxri-dev-profile-web`）。

## 通用说明

每条规则都带「适用前提」与「项目无对应物」两段。前提不成立、或项目里没有对应组件与工具时，整条跳过，不要求为满足规则新建替代物。具体组件名、平台名与工具命令见 [适配表](https://github.com/fxri-net/playbook/blob/main/skills/fxri-dev-profile-restore/./references/adapters.md)，示例与反例见 [原则示例](https://github.com/fxri-net/playbook/blob/main/skills/fxri-dev-profile-restore/./references/principles.md)。

## 规则

### 1. 素材分工与字段口径

- **适用前提**：同时存在设计稿与接口文档。
- **要求**：设计稿定视觉、布局与交互；接口文档定字段与业务口径；两者冲突以文档为准。设计稿字段不全时回接口类型定义与同族页面补全。
- **项目无对应物**：只有设计稿、没有文档时，字段以同族页面既有实现为准，并在任务档标注该假设。
- **反例**：照抄设计稿里缺失或占位的字段，把视觉稿当业务口径。

### 2. 素材缺失不造图

- **要求**：设计稿有、项目没有的图片与背景图，不自行造图、不占位、不改样式；提示用户在对应位置投放切片，到位后按设计稿实际效果选取，搬运到项目资源目录并沿用同目录命名风格。
- **反例**：用近似图、纯色块或占位图顶替设计稿资源。

### 3. 范围与复用优先

- **要求**：不做逐像素还原，优先复用项目既有组件与样式变量，保证结构与交互到位、视觉量与设计稿同量级；需求范围只覆盖任务清单内页面；纯跳板功能（仅唤起第三方应用、自身无页面内容）不做。
- **反例**：为像素偏差逐项调间距；实现清单外页面；为跳板功能自建替代实现。

### 4. 标注参数直读

- **适用前提**：设计稿提供结构化标注（图层树、标注面板或设计文件数据）。
- **要求**：尺寸、落位、圆角、旋转、配色、字号、透明度一律以结构化标注为准；坐标与圆角取标注实际字段，不凭位图目测反推。
- **项目无对应物**：只有位图、没有标注时按设计稿量取，并在结论中标注「按位图估读」。
- **反例**：把位图里量到的内容宽度直接当作样式宽度。

### 5. 位图只作三处佐证

- **要求**：位图切片只用于确认切片归属、内容占比、透明度是否已烘焙三项，不作为尺寸与样式的取值来源。
- **反例**：以整页位图逐像素比对替代标注取证，或以位图一致作为收工依据。

### 6. 双向取证判残留

- **要求**：标注图层树中存在某节点、但效果图对应位置未渲染其内容（空框、虚线占位、无可见图文）时，视为设计残留、不落地。判定须双向取证——图层树确认节点存在、效果图确认未渲染，两者同时成立；只凭其一仍按标注落地并向用户确认。
- **反例**：只查图层树就删元素，或只看效果图就下结论。

### 7. 整图切片与透明热区

- **适用前提**：设计以整张扁平图交付，文案与控件已合成在图内。
- **要求**：整图按锚点宽度等比渲染，不切子图、不另写文案覆盖；图内可点区域用透明热区按宽高百分比覆盖；整图设 `pointer-events: auto` 拦截点击；整图本身即点击域时不另设热区；空热区补可读语义属性。
- **项目无对应物**：无整图交付场景即整条不适用；不得为满足本条自建包装组件或占位图。
- **反例**：把烧进图内的文案切出来另写覆盖层；按固定像素计算热区坐标。

### 8. 内容文本可读下限

- **适用前提**：按设计稿还原界面。
- **要求**：承载信息、需阅读理解的文本（正文、描述、卡片与列表文字、说明）字号不低于项目可读下限，缺省 12px、项目配置优先；设计稿标注更小也按下限抬高；取值走项目既有字号档位变量，不逐页写死。
- **排除项**：装饰与标识小字、图内已合成文案、字号由「基准值 × 容器倍率」计算的元素不受限。
- **反例**：把设计稿为窄屏密集排版给出的 8px / 10px 内容文案原样落地。

### 9. 尺寸与字号走档位变量

- **要求**：字号、间距、尺寸按项目已有档位变量书写一次，由档位适配不同端或不同放大档；端专属覆盖块内写该端最终固定值，不再叠加动态档位。
- **项目无对应物**：项目无档位体系时按设计稿实际值书写，集中在样式变量中维护。
- **反例**：为两端各写一套字号；在覆盖块内再叠动态档造成二次放大。

### 10. 扁平大图切片获取

- **适用前提**：设计稿以单张扁平大图交付，页面结构里只有合成图、没有分层可导出图层。
- **要求**：从设计平台页面暴露的切片资源直链下载，请求带平台要求的防盗链请求头（来源与 UA），否则可能被拒；也可在页面内取回后转存；登录不可用时交用户登录后接管。
- **项目无对应物**：平台不提供直链时按平台导出能力逐张导出，并在任务档记录所用方式。
- **反例**：不带请求头直接请求直链，失败后归因于资源失效。

### 11. 设计平台可用态判定

- **要求**：以业务节点（画板、图层树、标注面板等）已渲染且几何可见（非零尺寸、在视口内）为主判定；登录或匿名提示文案只作辅助证据，命中文案须校验位置与尺寸，滚动出视口的隐藏节点不得判为登录墙。
- **反例**：页面文本命中「登录」即判登录墙，误报设计稿打不开。

### 12. 自绘可点元素取证

- **适用前提**：用浏览器自动化工具做点击取证，目标是无按钮语义的自绘可点元素。
- **要求**：无障碍快照把同类元素折叠为单行文本时，改用 DOM 快照按容器取子树，拿到逐项引用再点击；命中以业务态（选中类名、列表内容）判定。
- **反例**：拿折叠后的容器引用反复偏移点击；把选择器当引用传给点击命令。

### 13. 固定视口实测

- **要求**：实测移动端页面与接口时，在固定尺寸的同源 iframe 内操作，父页承载被测视口，脚本直接取 iframe 文档操作元素；不用设备模拟或拖拽窗口凑宽度。需要记录请求时在同源代理层注入探针。
- **项目无对应物**：无法使用 iframe 时改用固定视口尺寸的独立页，并在结论中注明视口尺寸。
- **反例**：用设备仿真或宿主窗口宽度模拟目标视口，导致坐标与断点判定失真。

### 14. 窄窗模拟分层判定

- **要求**：布局层（宽度驱动）与能力层（UA 或内核驱动）是两个独立开关，桌面窄窗只切换布局层；声明「移动端适配完成」不得只凭窄窗截图或布局类名成立，须真机或真触摸环境复核，或明确标注「仅覆盖窄窗、能力层未生效」。
- **反例**：凭窄窗截图或布局类名成立即声明移动端适配完成。

## 检查清单

- [ ] 字段口径以接口文档为准，冲突处已记录
- [ ] 未自造设计稿缺失的图片与背景图
- [ ] 未做逐像素还原，未实现清单外页面
- [ ] 取值来自标注参数，位图只用于三处佐证
- [ ] 图层有节点但效果图未渲染处已双向取证
- [ ] 整图切片用百分比热区承载点击，整图拦截点击
- [ ] 内容文本字号不低于可读下限（不适用的条目已标注跳过）
- [ ] 设计平台可用态按业务节点渲染判定
- [ ] 实测视口固定且同源，窄窗结论已标注覆盖范围
