# 隐私与安全

## 内容边界

- 不收录密钥、令牌、私钥、内网地址、客户数据与本机绝对路径。
- 示例使用泛化命名，不出现外部仓库实名。
- 技能正文不引用需要授权才能访问的资源。

## 检查

`node scripts/validate.mjs` 会扫描：

- 疑似密钥（`sk-` / `ghp_` / `AKIA` 前缀）
- 内网地址（`10.` / `192.168.` / `172.16–31.`）
- 本机用户目录（`C:\Users\` / `/Users/`）
- `file:///` 本机绝对链接
- 私钥块

发现遗漏请通过维护者邮箱私下报告，不要公开提交包含敏感信息的 issue。
