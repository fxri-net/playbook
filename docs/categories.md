# 分类说明

分类用于组织技能，不创建空技能目录。分类 `id` 即技能名首段（`fxri-<分类>-<类型>-<主题>`）。

## 归属判据

- 看「技能在哪个分类的场景里被使用」与「产出什么形态的交付物」，不看被处理对象的领域。
- 可运行实现归 `dev`；设计物料（视觉稿、交互稿、设计规范）归 `design`；文档与报告归 `writing` / `research`；数据产物、办公产物、环境变更各归其分类。
- 跨场景能力按主要使用场景归属，不为次要场景新开分类。
- 角色与场景称谓以本表与 `categories.json` 的定义为准，不在各处另造称呼。

## 新增分类的判定

只有同时满足以下条件才新增 category，否则用技能描述里的关键词表达：

1. 有独立受众（与现有分类的用户群明显不同）
2. 至少有 3 个规划中的技能
3. 无法归入现有分类
4. 能写清「使用者」与「交付物」两项定义

## 分类清单

| 分类 | 名称 | 说明 | 状态 |
| --- | --- | --- | --- |
| `dev` | 开发 | 前端、后端与工程化实践 | 使用中 |
| `office` | 办公 | 文档、表格与演示产物 | 预留 |
| `writing` | 写作 | 技术写作与内容表达 | 使用中 |
| `research` | 研究 | 检索、分析与报告 | 预留 |
| `design` | 设计 | 界面、交互与视觉规范 | 预留 |
| `data` | 数据 | 数据处理、分析与可视化 | 预留 |
| `ops` | 运维 | 部署、发布与稳定性 | 预留 |
| `meta` | 元技能 | 协作方式、预设与流程编排 | 使用中 |
| `imported` | 导入 | 第三方来源中未归类的技能（保留分类） | 预留 |

预留分类只登记说明，不建空技能目录；新增技能后由 `node scripts/gen-catalog.mjs` 自动进入目录与侧边栏。第三方来源使用未知分类时，工具侧不做分类校验，导入本仓时统一归入 `imported`。
