# 构建与质量示例

> 配合 `SKILL.md` 使用。每条先给正例，再给反例与后果。

## 1. 告警按来源归属治理

- 正例：自身样式声明顺序触发的弃用告警，把声明上移到嵌套规则之前，输出不变、告警消失；依赖包的告警按告警码精准过滤，其余照常暴露。
- 反例：把自身代码告警一并塞进过滤钩子，问题被永久掩埋；以「编译通过」作为验收结论。

## 2. barrel 成员不得回引自身

- 正例：聚合入口导出的组件内部改用相对路径直连被依赖的具体文件；断边前确认目标是默认导出还是命名导出。
- 反例：成员继续从聚合入口导入，构建期出现循环 chunk 告警，chunk 执行顺序错乱。

## 3. 质量门零告警

- 正例：静态检查收集告警与错误并标注级别，命令带「告警即失败」参数；本地执行前先自动修复改动文件。
- 反例：为拦住某类告警逐条提级规则；用通用 CI 变量判别流水线，本地终端也被判成流水线而跳过自动修复。

## 4. 接口契约生成优先

- 正例：契约生成的接口统一走既有请求实例，响应类型与手工接口同源；未收录接口在手工层登记待补，补入后迁移并删除手写实现。
- 反例：直接改生成文件补字段，下次重跑即被覆盖；生成接口另建请求实例，鉴权与错误提示全部失效。
