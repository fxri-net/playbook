# 文档站导航规范

> 本技能版本 0.2.0（随 playbook 技能集分发）。被问版本时即报此值；与磁盘版本不一致即说明会话上下文已过期。

## 何时使用

- 新建文档站，需要确定顶栏、侧栏与分类骨架
- 调整现有文档站的分类、命名或页面归属
- 评审文档站导航是否一致、是否可长期扩展

不涉及：页面正文写作、配图与视觉设计、部署流水线。

## 分类骨架

按用户意图分组，不按技术分层分组；按仓库实际裁剪，不硬凑。

| 分组 | 定位 | 收纳内容 |
| --- | --- | --- |
| 开始 | 第一次跑通 | 首页、快速开始 |
| 指南 | 场景化怎么做 | 操作手册、完整攻略、使用手册、开发指南、接入 |
| 参考 | 查询型内容 | CLI、API、配置 |
| 原理 | 为什么这样设计 | 架构、内核 |
| 升级 | 版本迁移 | 升级总览、API 对照、检查清单 |
| 开发 | 构建发布与协作 | 构建产物、分发接入、发版流程 |
| 帮助 | 求助与记录 | 常见问题、更新日志、贡献指南 |

> 示例：本仓在这套骨架上另设「技能 / 档案」组承载技能目录与档案总览——属本仓结构，不属通用分组。

## 命名规则

- 分组名 2 汉字优先，最长 4 汉字；禁止「内核与配置」这类「与」字复合名。
- 纯页面条目豁免长度限制；一级项与任何层级的分组名不豁免。
- 同一概念全站统一用词：快速开始（不用新手指南 / 快速上手）、操作手册、完整攻略、常见问题（不用 FAQ）、更新日志、贡献指南、接入。
- 页面 H1 与侧栏条目文案一致；不出现 `FAQ` 等英文缩写。
- 英文专有名词（CLI、API、SQL）按 1 项计，不计入字数上限。

## 顶栏规范

- 一级项不超过 5 个；首项固定「快速开始」直链，末项固定「帮助」下拉。
- 中间顺序：指南 → 参考 → 原理 / 升级 / 开发 / 领域组。
- 单个页面直接作一级直链，不包成单项下拉；下拉项 2–8 个，超出时按二级分组收纳。
- 更新日志、常见问题、贡献指南不单独占一级入口，统一由「帮助」承载。

## 扩展规则

- 后续新增页面优先并入现有分组，不新增一级分类；确需新增时须满足 ≤4 字并复核顶栏是否仍 ≤5 项。
- 侧栏二级分组仅在同类条目超过 8 个时启用，组名同样 ≤4 字。
- 升级文档按 `upgrade-<major>/` 独立目录扩展，历史版本不并入当前目录。
- 单页超过 300 行或同时承载两类读者时拆分；`changelog.md` 等生成镜像不拆。

## 校验方式

- 导航与侧栏以 `docs/site-nav.json` 为单一真源，站点配置只做引用展开；检查器读数据，不解析站点配置。
- 机器可检的阈值由工具命令执行：`toolkit docs nav check`（顶栏项数与首末项、帮助必备项、分组名长度、404 的 `search: false`、单页体量告警）与 `toolkit docs dist check`（站点地图与站内搜索索引排除 404）。下游不复制实现、不标注版本号。
- 工具未安装时相关检查跳过并提示，不阻断与该工具无关的仓库。
- 命令与本文件条款不一致时，以本文件条款为准，同时修命令。
- 单页超过 300 行（排除 `changelog.md`）输出 warn，只提示不阻断；更严格的正文可读性门禁属站点自选，不并入本条。

## 站点兜底（404 与索引排除）

只管导航失败时的去向，不涉及错误页的视觉与文案设计。

- 每站提供 `404.md`（首页、常见问题、更新日志入口），旧 URL 不重定向但可继续导航；404 页从站点地图过滤，并用 frontmatter `search: false` 排除站内搜索索引。
- 两条要求分两步执行：`docs nav check` 断言 `docs/404.md` 含 `search: false`；`docs dist check` 在构建之后断言产物（`sitemap.xml` 不含 404、搜索索引 chunks 不含 404 页标题），跳过构建的平台一并跳过。

## 落地步骤

1. 先定分组与命名，再改 `nav` / `sidebar` 配置。
2. 同步页面 H1、README 与文档索引里的旧称呼。
3. 修复站内链接与锚点（标题改名会改变页内锚点）。
4. 接入校验：把 `toolkit docs nav check` 与 `docs dist check` 纳入既有 verify 门禁，工具缺失时跳过。
5. 记录 patch 变更集，按仓库发版链路发布。

## 常见错误

- 把 FAQ、更新日志各挂一个顶栏入口，导致一级项膨胀。
- 用「接入与运维」「适配与答疑」这类复合长名，既超字数又混装两类内容。
- 导航指向锚点（如 `/cli#配置选项`）而不是独立页面，搜索与面包屑不可用。
- 校验写成页面白名单，新增页面就失效。
