# 前端通用规则详解

## 共享工具函数前缀

- 前缀来源是项目现状，不是个人偏好：项目已有 `fxXxx` 这类统一前缀，就沿用同一前缀风格。
- 新增共享工具前先全局检索同类工具的前缀，再决定命名。
- 不预设某个固定前缀，也不另行规定新前缀，一切以项目现状为准。

反例：项目共享工具统一以 `fx` 开头，新增工具改用另一套前缀，同类能力出现两套入口。

## 逐变量注释

- 每个变量单独注释，不把多个变量合并到一行注释。
- 注释写在该变量上方或同一行，说明它承载的数据或用途。
- 变量改名或含义变化时同步改注释。

反例：一行 `// 用户与订单数据` 同时覆盖 `user` 与 `order`，后续无法判断注释归属。

## 注释讲「为什么」

- 行内注释解释原因、约束与边界，不重复代码动作。
- 适合写注释的位置：分支条件、兼容处理、特殊取值、绕过某限制的原因。
- 代码本身能说明「做什么」时不再加注释。

反例：`// 将 a 赋值给 b` 只是复述代码，没有提供额外信息。

## 统一用词

- 固定使用「疏理」「配置」「返回」「校验」。
- 同一项目中不混用「整理 / 梳理」「设置 / 配置」「返回 / 回传」「校验 / 验证 / 检查」等近义词。
- 注释、文档与命名说明保持同一套动词。

## 函数名首字母排序

- 同一文件内的函数按英文首字母排序。
- 示例：`doBase → doData → doDom → doInfo → doOption → doParam → doRoute → doSafe → doSite → doUser`。
- 新增函数按排序插入，不追加到文件末尾。

## 效果图识别

- 忽略系统状态栏：时间、信号、网络、电量等运行环境指示。
- 忽略宿主容器 / 应用导航栏：返回、标题、窗口控制按钮等。
- 这些由运行环境或宿主容器提供，不属于页面本身要实现的内容。
- 只识别其下方真正的页面内容。

## 排障日志不是清理残留

- 诊断日志承担联调与线上排障职责，删掉后现场问题无法复现。
- 需要按环境收敛时，走统一日志封装或构建期门控，不逐个删调用。

反例：以「清理调试残留」为由批量删除业务代码里的日志。

## 大整数标识一律字符串

- 超出安全整数范围的数值标识，任何数值转换都会静默截断末位。
- 在路由参数、地址、接口参数、隐藏字段中保留接口下发的字符串原值。
- 需要去掉展示后缀时走字符串替换，不用数值函数顺带剥离。

反例：把字符串 ID 转成数值，跨端按 ID 查询时出现找不到资源。

## 运行期配置取值下沉

- 配置层顶层不静态导入环境配置文件、不直接读运行时状态容器。
- 取值下沉到函数体或模块初始化之后，规避初始化顺序与循环依赖。

反例：配置层顶层读运行时状态容器，启动即报初始化前访问。

## 失败提示分层与加载态复位

- 后端给了结构化消息就用它，不要用通用文案覆盖。
- 只有响应非结构化且状态码为服务端错误时，才用友好兜底文案。
- 异步取数链在收尾处复位加载态与弹层，异常路径同样复位。

反例：异常时加载态常驻，页面一直转圈。

## 浮层与可变高度底卡同容器让位

- 浮层控件与可显隐、高度可变的底部卡片放进同一纵向容器，由布局让位。
- 不写死偏移量；容器透传手势时不拦截，子元素各自拦截。
- 滚动区高度扣减贴底操作条高度，同一排布的多栏采用同一口径。

反例：控件写死底部偏移，卡片变高即被压住。

## 可选值访问统一范式

- 运行期可能为空的集合与对象，取值与索引一律用可选链。
- 同文件保持同一范式，便于判断哪些位置已防御。
- 已由渲染语义兜底、或初始化即保证为数组的集合，不重复防御。

反例：同文件一半可选链、一半直取，防御边界无法判断。

## 死样式判定

- 删除样式前回模板确认元素存在性。
- 被注释包裹、条件恒不成立但结构仍在的元素均属存在，不可删。
- 模板与注释中均无对应才是死样式；同选择器同值重复书写时删嵌套份不丢样式。

反例：仅凭选择器搜不到就删样式，恢复元素时样式已丢失。

## 根地址与拼接

- 作为基址的根地址不带尾斜杠。
- 手工模板拼接的路径带前导斜杠。
- 调整风格时根值与全部拼接点成对同步。

反例：只改根值漏改拼接点，拼出双斜杠或缺斜杠的地址。

## 间距分工

- 块与块之间用外边距留白，块自身内部用内边距留白，二者不混用。
- 间距不写死，取页面现状与同族页面已有的同量级值。

反例：把块间距写成内边距，块有背景时块间空隙被染成块底色。

## 图标只取项目图标库

- 图标优先取项目既有图标库，不引入第二套图标库。
- 不自造矢量图、不用近似图标顶替。
- 图标库缺图标时交用户投放并重新生成。

反例：引入第二套图标库或自造图形，全站风格分裂。

## 前缀同源

- 设计令牌、样式类名、运行时选择器字符串、会话分区名使用同一前缀。
- 按名字在运行时查找的选择器字符串须与类名同源同步修改。

反例：类名改了、运行时选择器没改，弹层挂到根节点导致定位错乱。

## 第三方 SDK 的取值与坐标系

- 字段名大小写与拼写以 SDK 实际为准。
- 首帧未完成布局时按固定间隔重试并设上限，成功后清理定时器。
- 对外统一产出同一种坐标系，转换收敛在封装层。

反例：字段名大小写写错导致校验恒为假；单次取值失败后永不派发事件。

## 整页刷新覆盖页面级数据

- 页面级数据接入下拉刷新：仅手势触发、与首屏并行、全部结束才收起动画、异常也要收尾。
- 程序触发的刷新不重复执行；一次性动作不接入。

反例：页面级数据只在首次挂载时拉取，下拉只刷新列表，其余区块保持旧值。
