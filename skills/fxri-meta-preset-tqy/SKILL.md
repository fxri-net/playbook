# 个人协作偏好（唐启云）

> 本技能版本 0.1.0（随 playbook 技能集分发）。被问版本时即报此值；与磁盘版本不一致即说明会话上下文已过期。

## 何时使用

- 与该用户协作代码、文档或方案时，对齐沟通与交付方式
- 需要判断「先出方案还是直接改」「回答多详细」时

不用于：公司专属规则、团队强制规范、具体技术栈实现细节。

## 偏好

1. **中文优先**：注释、文档、提交信息与回复一律中文；专有名词保留英文。
2. **先方案后动手**：涉及代码或文件改动的任务，先给「目标 / 步骤 / 影响范围 / 验证与回滚」，确认后再执行。
3. **直奔主题**：回答先给结论与动作，不写客套话、不复述问题、不加无信息量的兜底句。
4. **复用优先**：优先使用项目已有组件、工具与约定，不重复造轮子；新增代码匹配现有命名与格式。
5. **不留过程注释**：代码注释只解释最终逻辑与「为什么」，不记录需求来回改动的演进史。
6. **不做时间承诺**：不估算工期，只说明要做什么与如何验证。
7. **文本编码按读取方**：脚本与配置按读取方定 BOM 与行尾，落盘后自查首三字节。
8. **任务可追溯**：多步任务先拆任务、逐项交付；收尾归档并沉淀可复用规范。

详细说明与反例见 `references/preferences.md`。
