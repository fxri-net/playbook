# Vue 适配表

> 按「能力位」索引：项目存在等价物时按右列落地，不存在时整条跳过，不为满足规则新建替代物。

| 能力位 | 项目等价物判定 | 命中时 | 未命中时 |
| --- | --- | --- | --- |
| 列表容器组件 | 项目有以 props 数据源驱动自动加载的容器 | 显式传数据源，条件并入闭包 | 用原生列表，加载与刷新入口显式化 |
| 状态集合归类 | 页面有枚举、元素、数据三类集合的既有结构 | 按既有归类放置，注释沿用固定写法 | 按项目现有结构组织，不强造三分类 |
| 类型解析工具 | 项目有基于接口定义的参数与数据类型解析能力 | 经该工具取参数与数据类型 | 手写类型，改动契约时同步 |
| 富文本渲染组件 | 项目有清洗与解析富文本的组件 | 富文本字段经该组件渲染 | 以纯文本渲染并标注限制 |
| 路由参数入口 | 页面入口有统一的路由参数吸收方式 | 用既有方式吸收参数，跨页透传带上一页条件 | 直接用路由对象读取参数 |
| 表单禁用能力 | 表单组件支持递归设置禁用态 | 递归设置并隐藏提交入口 | 逐字段设置，补状态说明 |

## 使用纪律

- 适配条目只在命中时读取，不作正文要求。
- 项目等价物形态不同（命名、参数不同）时按其实际形态落地。
- 表内没有的能力位不推断，回到 `SKILL.md` 的原则层判断。
