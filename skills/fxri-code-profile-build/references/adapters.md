# 构建与质量适配表

> 按「能力位」索引：项目存在等价物时按右列落地，不存在时整条跳过，不为满足规则新建替代物。

| 能力位 | 项目等价物判定 | 命中时 | 未命中时 |
| --- | --- | --- | --- |
| 告警过滤钩子 | 构建工具提供按告警码过滤的回调 | 只过滤依赖包告警，保留其余 | 只做源头治理，任务档记录无法过滤的告警码 |
| 聚合导出入口 | 存在统一导出文件与对应路径别名 | 成员侧改为直连具体文件 | 无聚合导出时整条不适用 |
| 聚合验收命令 | 本地与流水线共用一条聚合校验命令 | 告警与错误一并阻断，本地先自动修复 | 在任务档记录现有校验入口与缺口 |
| 流水线环境变量 | 流水线注入专用环境变量 | 用它判别是否跳过自动修复 | 用「是否存在流水线配置文件」等可观测事实判别 |
| 契约生成工具 | 接口类型由契约工具产出并可重跑 | 生成物不手改，手工层登记待迁移 | 手工接口集中单一入口，登记待迁移清单 |
| 统一请求实例 | 项目有统一的请求客户端与拦截器 | 生成接口复用同一实例与响应类型 | 在调用点统一封装，避免多套实例 |
| 真实调用点 | 可对至少一个接口发真实请求 | 生成后实测一次，结论写入任务档 | 向开发者确认可用的验证渠道后再交付 |

## 使用纪律

- 适配条目只在命中时读取，不作正文要求。
- 项目等价物形态不同（命令、参数、变量名不同）时按其实际形态落地。
- 表内没有的能力位不推断，回到 `SKILL.md` 的原则层判断。
