# 数据展示适配表

> 按「能力位」索引：项目存在等价物时按右列落地，不存在时整条跳过，不为满足规则新建替代物。

| 能力位 | 项目等价物判定 | 命中时 | 未命中时 |
| --- | --- | --- | --- |
| 码值映射表 | 页面或公共模块有「码值 → 可读文本」的映射结构 | 映射优先 + 原值兜底，就近复用既有映射 | 在用到处新建小表，命名与结构跟随同族页面 |
| 字典接口 | 后端提供按维度取选项的字典能力 | 选项文本与提交值同取字典字段，前端不加工 | 问开发者确认来源；未就绪可本地数组并标注回迁 |
| 契约生成物 | 接口类型由契约工具生成 | 不手改生成物，缺失回上游补契约 | 手写类型并标注来源，改动契约时同步 |
| 响应统一层 | 存在统一响应拦截器与成功判定 | 按契约取值，不在该层做结构兼容 | 在调用点按实测结构取值并记录 |
| 页面级状态集合 | 页面有枚举集合或常量集合的既有归类 | 映射表放入该集合，保持页面结构一致 | 放在使用处附近的常量文件 |
| 字段形态实测入口 | 能对接口发真实请求并查看响应 | 先实测再定写法，结论写入任务档 | 向开发者确认真实契约后再实现 |

## 使用纪律

- 适配条目只在命中时读取，不作正文要求。
- 项目等价物形态不同（命名、参数不同）时按其实际形态落地。
- 表内没有的能力位不推断，回到 `SKILL.md` 的原则层判断。
