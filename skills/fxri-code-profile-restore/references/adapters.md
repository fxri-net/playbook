# 设计还原适配表

> 按「能力位」索引：项目存在等价物时按右列落地，不存在时整条跳过，不为满足规则新建替代物。

| 能力位 | 项目等价物判定 | 命中时 | 未命中时 |
| --- | --- | --- | --- |
| 设计平台切片直链 | 平台页面结构里暴露切片资源的直接下载地址 | 带平台要求的来源与 UA 请求头下载，或页面内取回转存 | 按平台导出能力逐张导出，任务档记录方式 |
| 设计标注数据 | 平台提供图层树、标注面板或设计文件结构化数据 | 逐节点读尺寸、坐标、圆角、填充、字体、透明度 | 按位图量取，结论标注「按位图估读」 |
| 样式档位变量 | 项目有按基准像素生成的多档尺寸变量 | 只按设计基准写一次，档位自动适配 | 按设计稿实际值写，集中在样式变量中维护 |
| 字号可读下限 | 项目规范或样式库定义了内容文本最小字号 | 取项目下限，走档位变量 | 用例中缺省 12px |
| 资源目录与命名 | 项目有约定的图片资源目录与命名风格 | 按同目录既有风格命名与引用 | 放入项目通用资源目录，命名保持可辨识 |
| 点击承载方式 | 整图交付且需图内子区域可点 | 百分比定位的透明热区 + 整图拦截点击 | 无整图场景时整条不适用 |
| 无障碍语义补充 | 热区为空元素且需按语义定位 | 补按钮语义与可读标签 | 仅内部使用、无语义定位需求时补可读标签即可 |
| 浏览器自动化工具 | 具备 DOM 快照与按容器取子树的能力 | 用 DOM 快照取逐项引用再点击 | 改用业务态定位（选中类名、列表内容） |
| 同源承载容器 | 测试环境可提供同源 iframe 或固定尺寸独立页 | 在容器内操作元素、注入请求探针 | 用固定视口尺寸的独立页并注明尺寸 |
| 真机或真触摸环境 | 可获取真机、真触摸或远程调试通道 | 真机复核能力层后再声明适配完成 | 结论明确标注「仅覆盖窄窗、能力层未生效」 |

## 使用纪律

- 适配条目只在命中时读取，不作正文要求。
- 项目有等价物但形态不同（名字、参数不同）时，按其实际形态落地，不改造成表内形态。
- 表内没有的能力位不推断，回到 `SKILL.md` 的原则层判断。
