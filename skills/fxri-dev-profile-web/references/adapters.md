# 前端通用适配表

> 按「能力位」索引：项目存在等价物时按右列落地，不存在时整条跳过，不为满足规则新建替代物。

| 能力位 | 项目等价物判定 | 命中时 | 未命中时 |
| --- | --- | --- | --- |
| 图标库 | 项目有统一的图标资源目录与命名约定 | 只从该库取图标，缺图标交用户投放后重新生成 | 图标纳入统一资源目录与命名约定，不分散在各页面 |
| 日志收敛通道 | 项目有日志封装或构建期门控 | 通过封装按环境收敛输出 | 保留日志原样，不逐条删除 |
| 运行期状态容器 | 项目以运行时容器承载环境配置 | 经容器读取，取值下沉到函数 | 经构建期注入读取，切换环境时重新构建 |
| 列表容器组件 | 项目有承载分页列表的封装组件 | 按该组件的数据源属性接入刷新与加载 | 用原生列表实现，刷新入口显式化 |
| 图标与样式令牌前缀 | 项目已定义令牌与类名前缀 | 新令牌与类名沿用同前缀，选择器字符串同步 | 先统一前缀再新增，避免并存多套 |
| 第三方 SDK | 项目引入地图、播放器等外部 SDK | 按其实际字段名取值，坐标转换收敛在封装层 | 无第三方 SDK 时整条不适用 |
| 静态检查工具 | 项目有可自动修复的静态检查 | 本地先自动修复改动文件再判定 | 手工修复后在验收中统一判定 |
| 构建期门控 | 构建工具支持按环境裁剪代码 | 用门控收敛日志与调试逻辑 | 用日志封装按运行时开关收敛 |

## 使用纪律

- 适配条目只在命中时读取，不作正文要求。
- 项目等价物形态不同（命名、参数、目录不同）时按其实际形态落地。
- 表内没有的能力位不推断，回到 `SKILL.md` 的原则层判断。
