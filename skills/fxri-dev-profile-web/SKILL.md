# 前端通用规范

> 本技能版本 0.3.0（随 playbook 技能集分发）。被问版本时即报此值；与磁盘版本不一致即说明会话上下文已过期。

## 何时使用

- 需要约定前端工程的共享工具命名、注释组织、函数排序时
- 需要按设计稿识别页面内容、排除宿主框架性头部时
- 处理数值精度、运行期取值、失败提示、布局让位、可选值访问、死代码判定等跨框架共性写法时
- 与 Vue / 具体框架无关的通用前端约定

不涉及：格式化、状态三分类、Defines / AxiosParse、SFC 语法与 JSDoc 语法（见 `fxri-dev-profile-vue`）；设计还原的取证口径（见 `fxri-dev-profile-restore`）。

## 通用说明

第 7 条起每条带「适用前提」与「项目无对应物」两段，前提不成立即整条跳过。组件、图标库、构建工具与 SDK 的具体形态见 [适配表](./references/adapters.md)。

## 规则

### 1. 共享工具函数前缀

- **要求**：共享工具函数的前缀始终跟随项目里已有的前缀，不另起一套。
- **做法**：项目已有 `fxXxx` 这类统一前缀时，新增共享工具沿用同一前缀风格。
- **反例**：项目共享工具统一以 `fx` 开头，新增工具却另起一套前缀，导致同一类工具出现两套入口。

### 2. 逐变量注释

- **要求**：每个变量单独写简短注释，不把多个变量挤在一行注释里。
- **做法**：注释紧贴变量所在行或上方，说明该变量承载什么。
- **反例**：`// 用户与订单数据` 一行注释覆盖两个不同变量，后续无法判断注释对应哪一个。

### 3. 注释讲「为什么」

- **要求**：行内注释解释为什么这样写，而不是复述代码在做什么。
- **做法**：在分支、兼容处理、特殊取值处说明原因与约束。
- **反例**：`// 赋值给 a` 这类只复述动作的注释。

### 4. 统一用词

- **要求**：描述动作与结果时统一使用「疏理」「配置」「返回」「校验」等既有用词，不混用近义词。
- **做法**：同一类操作在注释、文档与命名说明中保持同一动词。
- **反例**：同一项目中「整理 / 疏理 / 梳理」混用，「校验 / 验证 / 检查」混用。

### 5. 函数名按英文首字母排序

- **要求**：同一文件内的函数按函数名英文首字母排序。
- **做法**：如 `doBase → doData → doDom → doInfo → doOption → doParam → doRoute → doSafe → doSite → doUser`。
- **反例**：函数按编写时间或调用顺序随意排列，新增函数插在中间导致顺序持续漂移。

### 6. 效果图识别

- **要求**：识别 UI 效果图时忽略非页面内容本身的框架性头部。
- **做法**：忽略系统状态栏（时间、信号、网络、电量）与宿主容器 / 应用导航栏（返回、标题、窗口控制按钮），只识别其下方真正的页面内容。
- **反例**：把手机状态栏或宿主应用标题栏当成页面组件实现。

### 7. 排障日志不是清理残留

- **要求**：诊断类日志调用不得作为「清理调试残留」批量删除；需要按环境收敛输出时，走统一日志封装或构建期门控。
- **反例**：以「生产环境不该有日志」为由逐个删业务代码里的日志，现场问题无法复现，只能临时插桩重建。

### 8. 大整数标识一律字符串

- **要求**：超出安全整数范围的数值标识（如雪花 ID）在路由参数、地址、接口参数、隐藏字段中一律保留接口下发的字符串原值，不做任何数值转换；需要处理展示后缀时走字符串操作。
- **反例**：把字符串 ID 转成数值后末位被静默截断，跨端按 ID 查询时才暴露为找不到资源。

### 9. 运行期配置取值下沉

- **要求**：环境配置经运行期读取；配置层顶层不做编译期静态导入、不直接读运行时状态容器；取值下沉到函数体或模块初始化之后，规避初始化顺序与循环依赖。
- **反例**：配置层顶层直接读运行时状态容器，启动即报「初始化前访问」。

### 10. 失败提示分层与加载态复位

- **要求**：失败提示优先用后端返回的结构化消息；仅当响应非结构化（HTML、空体）且状态码为服务端错误时，才使用友好兜底文案。异步取数链在收尾处一律复位加载态与弹层，异常路径同样复位。
- **反例**：失败只弹通用文案、丢弃后端消息；异常时加载态常驻，页面卡在加载中。

### 11. 浮层与可变高度底卡同容器让位

- **要求**：依附同一区域的浮动控件与可显隐、高度可变的底部卡片，放进同一个底部锚定的纵向容器，由布局让位，不写死偏移量；容器需透传手势时不拦截、子元素各自拦截；滚动区高度扣减贴底操作条高度。
- **反例**：控件写死底部偏移，卡片变高即被压住；滚动区与贴底栏高度口径不一致，末项被遮住。

### 12. 可选值访问统一范式

- **要求**：运行期可能为空的集合与对象，取值与索引一律用可选链，同文件保持同一范式；已由渲染语义兜底的场景（列表渲染、条件为假不求值）不重复防御；初始化即保证为数组的集合不再逐处防御。
- **反例**：同文件一半可选链、一半直取，无法判断哪些位置已防过。

### 13. 死样式判定

- **要求**：删除样式前回模板确认元素存在性——被注释包裹、条件恒不成立但结构仍在的元素均属存在，不可删；模板与注释中均无对应才是死样式。同一选择器同值重复书写时，删除嵌套份不丢样式。
- **反例**：仅凭选择器搜不到就删样式，将来恢复元素时样式已丢失、无从对应。

### 14. 根地址与拼接

- **要求**：作为基址的根地址一律不带尾斜杠；手工模板拼接的路径一律带前导斜杠；调整风格时根值与全部拼接点成对同步。
- **反例**：只改根值漏改拼接点，拼出双斜杠或缺斜杠的地址。

### 15. 间距分工

- **要求**：块与块之间的留白用外边距，块自身内部留白用内边距，二者不混用；间距不写死固定值，取页面现状与同族页面已有的同量级值。
- **反例**：把块间距写成内边距，块有背景或圆角时块间空隙被染成块底色。

### 16. 图标只取项目图标库

- **要求**：图标优先取项目既有图标库；不引入其他图标库、不自造矢量图、不用近似图标顶替；图标库缺图标时交用户投放并重新生成，不由实现方替代。
- **项目无对应物**：项目无图标库时，图标纳入统一的资源目录与命名约定，不分散在各页面。
- **反例**：引入第二套图标库或自造图形，全站风格分裂。

### 17. 前缀同源

- **要求**：设计令牌、样式类名、运行时选择器字符串、会话分区名使用同一前缀；按名字在运行时查找的选择器字符串须与类名同源同步修改。
- **反例**：类名改了、运行时选择器没改，弹层找不到容器而退回挂到根节点，定位错乱。

### 18. 第三方 SDK 的取值与坐标系

- **适用前提**：项目使用第三方 SDK，且其返回值参与业务判断。
- **要求**：字段名大小写与拼写以该 SDK 实际为准；首帧未完成布局导致取值不完整时，按固定间隔重试并设上限，成功后清理定时器；对外统一产出同一种坐标系。
- **项目无对应物**：项目无第三方 SDK 时整条不适用。
- **反例**：字段名大小写写错导致校验恒为假；单次取值失败后永不派发事件，业务侧无任何报错。

### 19. 整页刷新覆盖页面级数据

- **适用前提**：整页由列表容器承载，页面内还有首屏外的页面级数据。
- **要求**：页面级数据须接入下拉刷新——仅手势触发、与首屏并行、全部结束才收起动画、异常也要收尾；程序触发的刷新不重复执行；一次性动作不接入。
- **项目无对应物**：列表容器不支持页面级参与点时不接入，改为显式刷新入口。
- **反例**：页面级数据只在首次挂载时拉取，下拉只刷新列表，其余区块保持旧值。

## 检查清单

- [ ] 共享工具函数沿用项目已有前缀
- [ ] 每个变量有独立简短注释
- [ ] 行内注释解释「为什么」
- [ ] 动词用词统一
- [ ] 函数按英文首字母排序
- [ ] 设计稿只还原页面内容，忽略宿主框架性头部
- [ ] 大整数标识全程字符串，未做数值转换
- [ ] 失败提示分层，异常路径也复位加载态
- [ ] 浮层未写死偏移，滚动区扣减贴底栏高度
- [ ] 可选链同文件同范式，未过度防御
- [ ] 删除样式前已确认模板元素不存在
- [ ] 根地址无尾斜杠、拼接带前导斜杠
- [ ] 块间距与块内留白未混用
- [ ] 图标来自项目图标库，未自造
- [ ] 前缀与运行时选择器同源
