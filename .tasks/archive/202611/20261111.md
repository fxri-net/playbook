# 新建设计还原技能

> 计划位置：第 2 个（共 6 个）；前置：20261111-唐启云-沉淀技能命名与分类归属规范；后继：20261111-唐启云-前端通用规范扩章

## 背景

按设计稿还原页面时反复踩同一批坑：素材缺失自行造图、凭位图反推尺寸、整图切片不会承载点击、内容小字被压到不可读、设计平台登录态误判。这些做法已在两个外部仓各自沉淀成 16 条规范，条文高度同构，属同一类可迁移知识，但都绑定了各自的组件名、路径与平台细节。

本任务把这 16 条按「原则层 / 适配层」拆开，原则进正文，组件与平台细节进 references，使任何前端工程命中即可用、依赖项缺失时相关条目自动跳过。

## 实施方案

新建技能目录 `skills/fxri-dev-profile-restore/`，版本 0.1.0，category `dev`，type `profile`，scope `[web]`，triggers 覆盖设计还原、设计稿取证、切片、整图热区、字号下限、窄窗模拟等意图。

SKILL.md 正文 13 条规则，每条统一「适用前提 / 要求 / 项目无对应物 / 反例」四段：

1. 素材分工与字段口径（设计稿定视觉、接口文档定字段，冲突以文档为准）。
2. 素材缺失不造图、不占位，交用户投放。
3. 范围与复用优先：不做逐像素还原、只做任务清单内页面、不做纯跳板功能。
4. 标注参数直读为主，位图只作切片归属、内容占比、透明度是否烘焙三处佐证，不反推尺寸。
5. 图层有节点但效果图未渲染时，须双向取证才判为设计残留、不还原。
6. 整图切片与透明热区：整图等比渲染、百分比热区承载子区域点击、整图拦截点击、整图本身即点击域时不另设热区、空热区补可读语义。
7. 内容文本可读下限：缺省 12px、项目配置优先；装饰小字、图内烧死文案、倍率缩放元素三类排除。
8. 尺寸与字号走项目档位变量，PC 覆盖块内写固定值、不叠动态档。
9. 扁平大图的切片获取：从页面 DOM 取切片直链，请求带防盗链所需请求头；登录不可用时交用户。
10. 设计平台可用态判定：业务节点已渲染且几何可见为主，提示文案仅作辅助并须校验位置与尺寸。
11. 自绘可点元素取证：无障碍快照折叠为单行时改 DOM 快照按容器取子树；命中以业务态判定。
12. 固定视口实测：同源 iframe 固定尺寸承载被测页面，不用设备模拟或拖拽窗口凑宽度。
13. 窄窗模拟移动端：布局层与能力层分开判定，声明适配完成须真机复核或标注只覆盖窄窗。

# 沉淀技能命名与分类归属规范

> 计划位置：第 1 个（共 6 个）；前置：无；后继：20261111-唐启云-新建设计还原技能、20261111-唐启云-新建接口契约与数据展示技能、20261111-唐启云-新建构建与质量技能、20261111-唐启云-前端通用规范扩章、20261111-唐启云-Vue-前端规范扩章

## 背景

从外部仓的 45 条通用规范提炼技能时暴露两处治理空白。其一，技能命名没有「不得占领域大分类」的约束，`fxri-ui-*`、`fxri-data-*` 这类命名会用单个技能宣称整个领域，与「综合实践技能集」的定位冲突。其二，分类归属没有可执行判据，设计还原这类「按设计稿实现页面」的能力容易被误归入设计分类。

两处都属一次定终身的口径（分类 id 即技能名首段，改名破坏安装引用），须先立规范与门禁，后续新建技能才有据可依。

## 实施方案

1. `.tasks/conventions/common.md` 新增两条条文：
   - C-3 技能命名与技能集定位：三段式 `fxri-<分类>-<类型>-<主题>`，分类取 categories.json 的 id，类型取 validate 的类型枚举，主题为具体能力词；主题不得为 ui / data / web / app / frontend / engineering 等领域大词；一技能一主题；存量旧名不改名。
   - C-4 分类归属按使用场景：判据为「在哪个分类的场景里被使用 + 产出什么形态的交付物」，不看被处理对象的领域；角色与场景称谓一律取该分类的 label 与 description，不新造岗位名；跨场景能力按主要使用场景归属；新增分类须同时写明使用者与交付物。
2. `.tasks/conventions/index.md` 索引表新增 C-3、C-4 两行，归属 common，单一事实源 `common.md`。
3. `AGENTS.md` 协作流程约束新增一条「新建技能须符合 conventions 的 C-3 / C-4」，并同步更新首部规则更新时间。
4. `CONTRIBUTING.md` 新增技能命名规则由 `fxri-<分类>-<名称>` 细化为三段式，写明分类段与类型段的取值来源、主题段禁用领域大词。
5. `docs/contributing.md` 同步手写镜像内容。
6. `docs/categories.md` 补充分类 id 即技能名首段、交付物判据，以及新增分类须写明使用者与交付物的前置要求。
7. `README.md` 第 12 行定位由「面向 AI 协作的工程规范集」改为「面向 AI 协作的综合实践技能集」，第 14 行「工程经验」改为「实践经验」。
8. `scripts/validate.mjs` 新增命名校验：取 git 基准（沿用文件内既有 getBaseline 机制），只校验基准之后新增的技能名，须匹配 `fxri-<category>-<type>-<主题>`，且主题段不含领域大词；无基准时打印「跳过（无 git 基准）」，不静默放行。
9. `.changeset/` 新增 patch 变更集，条目逐条以 `- 类型：描述` 书写。
